# Проверенные сервисы — Система ОП

Картотека проверенных сервисов (интеграторы, инструменты, платформы), которые использует команда «Система ОП».
Одна страница `index.html`, деплой на GitHub Pages.

## Как добавить сервис
1. Положи фото/логотип в папку `img/` (например `spec-02.jpg`).
2. В `index.html` найди список `SPECIALISTS` и скопируй один блок `{ ... }`, заполни поля.
   Номер WhatsApp — только цифрами, без + и пробелов.
